Unlike agents that decide their own path, state machines **must follow the specified workflow**.\n\n### TypedDict\nA Python structure that defines what fields a dictionary must contain. Ensures all nodes have access to the same data structure.\n\n### Immutable State\nEach node creates **new state** instead of modifying existing state. This makes debugging easier and enables undo/rollback capabilities.\n\n### Conditional Edges\nEdges that choose the next node based on a **condition** (like validation result). Used for branching workflows.\n\n### Audit Trail\nThe `workflow_path` list that records **all steps taken**, providing complete traceability for compliance and debugging.\n\n### Node Functions\nFunctions that take state as input, process it (often using an LLM), and return updated state. Each node is responsible for one step.\n\n---\n\n## ⚠️ Important Notes\n\n### API Key\n- Required from https://platform.openai.com/api-keys (free tier OK)\n- Never share or commit to public repos\n- If exposed, delete and create new one\n- ~$0-2 cost for testing\n\n### Running Order\n- **MUST run cells in order** (don't skip or reorder)\n- First run includes installation (takes time)\n- Subsequent runs are faster (skip installation)\n- Can interrupt and resume (state is in notebook)\n\n### Prompts\n- **7 times** you'll be asked for input\n- Simple yes/no or category answers\n- Copy-paste answers provided if needed\n- Just follow the guide when prompted\n\n---\n\n## 🎓 After Completion\n\nYou should create:\n\n1. **lab_summary.md**\n   - One paragraph comparing LangGraph vs LangChain\n   - When to use each\n   - Trade-offs\n   - Place at repo root\n\n2. **GitHub Repository**\n   - notebook.ipynb (with outputs visible)\n   - lab_summary.md\n   - README.md (how to run)\n   - All supporting docs\n   - Push and share URL\n\n---\n\n## 📞 Support Resources\n\nIf stuck, check:\n\n1. **For overview questions**: README.md\n2. **For navigation**: INDEX.md\n3. **For quick reference**: QUICK_CHEAT_SHEET.md\n4. **For detailed explanation**: NOTEBOOK_GUIDE.md\n5. **For input prompts**: HUMAN_INTERVENTION_GUIDE.md\n6. **For errors**: NOTEBOOK_GUIDE.md \"Troubleshooting\"\n\n---\n\n## 🎉 You're Ready!\n\n**Everything you need is here.** Start with:\n\n1. **README.md** (2 min read for context)\n2. **QUICK_CHEAT_SHEET.md** (1 min scan for roadmap)\n3. **NormalObjects_LangGraph_Lab_Notebook.ipynb** (run it!)\n4. **Keep HUMAN_INTERVENTION_GUIDE.md handy**\n\n**You've got this!
